# Drug Discovery AI — Streamlit Application

A professional Streamlit application for **molecular virtual screening and drug-likeness profiling** based on the workflow in the supplied Jupyter notebook.

## Features

- SMILES validation and parsing with RDKit
- 2D molecular structure rendering
- Seven physicochemical descriptors:
  - Molecular Weight
  - LogP
  - TPSA
  - H-bond Donors
  - H-bond Acceptors
  - Rotatable Bonds
  - Aromatic Rings
- XGBoost bioactivity classification
- Random Forest bioactivity classification
- Active-class probability
- Lipinski Rule of Five screening
- Batch CSV virtual screening
- Downloadable prediction results
- Model performance comparison
- Dataset explorer
- Cached model/data loading for better Streamlit performance

## Project structure

```text
drug_discovery_streamlit/
├── app.py
├── train_models.py
├── requirements.txt
├── README.md
├── .gitignore
├── data/
│   └── drug_discovery_10k_dataset.csv
└── models/
    ├── xgboost_model.joblib
    ├── random_forest_model.joblib
    └── metadata.json
```

The `models/` files are generated by `train_models.py` and are not required initially because `app.py` can train the models automatically if they are missing.

## Dataset requirements

Place the notebook's dataset at:

```text
data/drug_discovery_10k_dataset.csv
```

The dataset must contain these columns:

```text
SMILES
Prediction_Class
MW_g_mol
LogP
TPSA_A2
HBD_Count
HBA_Count
Rotatable_Bonds
Aromatic_Rings
```

`Prediction_Class` should contain the labels `ACTIVE` and `INACTIVE`.

## Installation

### 1. Create a virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

If RDKit installation gives an environment-specific error, install RDKit using the package manager recommended for your Python distribution, then install the remaining requirements.

### 3. Add the dataset

Copy:

```text
drug_discovery_10k_dataset.csv
```

into:

```text
data/drug_discovery_10k_dataset.csv
```

### 4. Train and save the models

Recommended for deployment:

```bash
python train_models.py
```

This creates:

```text
models/xgboost_model.joblib
models/random_forest_model.joblib
models/metadata.json
```

### 5. Run Streamlit

```bash
streamlit run app.py
```

The application will open in your browser.

## Streamlit application pages

### Overview
Shows dataset size, model status, feature count, and the complete screening workflow.

### Single Molecule
Enter a SMILES string and select XGBoost or Random Forest. The application displays:

- 2D chemical structure
- predicted class
- active probability
- physicochemical descriptors
- Lipinski Rule-of-Five status

### Batch Screening
Upload a CSV with a `SMILES` column. The application processes every molecule and generates a downloadable CSV containing predictions, probabilities, descriptors, and Lipinski results.

### Model Performance
Evaluates XGBoost and Random Forest on a stratified 20% test split and reports:

- Accuracy
- Precision
- Recall
- F1
- ROC-AUC

### Dataset
Provides a read-only dataset preview, class distribution, and missing-value summary.

## Important modeling note

The supplied notebook contains a PyTorch GNN class, but the GNN is **initialized rather than trained on the labeled dataset**. It therefore should not be presented as a valid production prediction model.

For that reason, this Streamlit application uses the two models that are actually trained in the notebook:

- XGBoost
- Random Forest

A trained GNN can be added later after a proper molecular graph training pipeline, validation split, checkpointing, and independent evaluation have been implemented.

## Security and deployment recommendations

For a real deployment:

1. Do not allow arbitrary file paths from users.
2. Validate uploaded CSV size and schema.
3. Add authentication if the application contains proprietary datasets.
4. Pin exact dependency versions after validating the deployment environment.
5. Store model artifacts in a controlled model registry or object store.
6. Log model version, dataset version, and inference timestamp.
7. Do not treat model predictions as medical advice, clinical decisions, or regulatory evidence.

## Deploying to Streamlit Community Cloud

Push the project to a Git repository with this structure:

```text
app.py
train_models.py
requirements.txt
README.md
data/drug_discovery_10k_dataset.csv
models/xgboost_model.joblib
models/random_forest_model.joblib
models/metadata.json
```

Then select `app.py` as the Streamlit entry point.

For large/private datasets, do not commit the dataset to a public repository. Use secure storage and adapt `DATA_PATH` to the approved storage mechanism.
